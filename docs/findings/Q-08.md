# Q-08 — Missing meta description

**Chapter:** quality  
**Rule:** `meta-description`  
**Spec:** [Missing meta description](https://morkeleb.github.io/clickmonkey/findings/Q-08/)

No unique meta description. Search snippets and social fallbacks are empty or generic.

Add a one- or two-sentence description that is not a copy of the title. Not this: missing document.title (WCAG 2.4.2).
