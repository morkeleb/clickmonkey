# T-04 — Unlabeled field

**Chapter:** testability  
**Rule:** `unlabeledField`  
**Spec:** [Unlabeled field](https://morkeleb.github.io/clickmonkey/findings/T-04/)

The field has no label. Users cannot tell what to type, and autofill, specs, and junk-fill targeting all miss.

A <label for>, aria-label, or wrapping label is enough. Placeholder-only is not a name.

This id is **stable**. Reports link here so T/V/Q classes do not shuffle when a soak ranks differently.
