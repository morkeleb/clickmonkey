# V-14 — Scroll padding vs sticky header

**Chapter:** visual  
**Rule:** `scrollPadding`  
**Spec:** [Scroll padding vs sticky header](https://morkeleb.github.io/clickmonkey/findings/V-14/)

Sticky/fixed header is taller than scroll-padding-top, so keyboard focus tucks under the chrome.

Companion to WCAG 2.4.11. Padding must be at least the sticky header height.

This id is **stable**. Reports link here so T/V/Q classes do not shuffle when a soak ranks differently.
