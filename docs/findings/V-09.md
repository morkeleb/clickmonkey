# V-09 — Text occlusion

**Chapter:** visual  
**Rule:** `textOcclusion`  
**Spec:** [Text occlusion](https://morkeleb.github.io/clickmonkey/findings/V-09/)

Text is hidden under a control, icon, or badge.

Labels and values become unreadable even when the DOM still has the full string.

This id is **stable**. Reports link here so T/V/Q classes do not shuffle when a soak ranks differently.
