# WCAG 1.4.12 Text spacing

**Chapter:** accessibility · WCAG 1.4.12 AA  
**Rule:** `textSpacing`  
**WCAG:** [WCAG 1.4.12 Text spacing](https://www.w3.org/WAI/WCAG22/Understanding/text-spacing.html) — official.

When line-height, letter-spacing, and word-spacing are increased to WCAG 1.4.12 values, text clips or the pane overflows. Low-vision users who space letters cannot read the control.

This handle is only “we found `textSpacing`.” The requirement is the W3C page, not this catalog.
