# WCAG 2.4.11 Focus not obscured

**Chapter:** accessibility · WCAG 2.4.11 AA  
**Rule:** `focusObscured`  
**WCAG:** [WCAG 2.4.11 Focus not obscured](https://www.w3.org/WAI/WCAG22/Understanding/focus-not-obscured-minimum.html) — official.

The control is entirely hidden when it receives keyboard focus (WCAG 2.4.11). Keyboard users cannot see where they are; sticky chrome or a cookie/chat widget ate the focus.

This handle is only “we found `focusObscured`.” The requirement is the W3C page, not this catalog.
