# V-12 — Implicit submit

**Chapter:** visual  
**Rule:** `implicitSubmit`  
**Spec:** [HTML button type](https://html.spec.whatwg.org/multipage/form-elements.html#attr-button-type)

A <button> with no type inside a form defaults to submit. Cancel can send the form by accident.

HTML default type is submit. Set type=button on non-submit actions.

This id is **stable**. Reports link here so T/V/Q classes do not shuffle when a soak ranks differently.
