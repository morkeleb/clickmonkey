# AXE scrollable-region-focusable

**Chapter:** accessibility · WCAG 2.1.1 A  
**Rule:** `scrollable-region-focusable`  
**axe:** [AXE scrollable-region-focusable](https://dequeuniversity.com/rules/axe/4.13/scrollable-region-focusable) — official.

A scrollable region cannot take focus. Keyboard users cannot scroll to the rest of the content.

This handle is only “we found `scrollable-region-focusable`.” The requirement is the Deque page, not this catalog.
