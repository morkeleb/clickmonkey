# AXE nested-interactive

**Chapter:** accessibility · WCAG 4.1.2 A  
**Rule:** `nested-interactive`  
**axe:** [AXE nested-interactive](https://dequeuniversity.com/rules/axe/4.13/nested-interactive) — official.

A button or link is inside another. Keyboard users tab twice to one control; the inner action is easy to miss or fire twice.

This handle is only “we found `nested-interactive`.” The requirement is the Deque page, not this catalog.
