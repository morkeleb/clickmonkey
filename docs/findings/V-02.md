# V-02 — Clip

**Chapter:** visual  
**Rule:** `clip`  
**Spec:** [Clip](https://morkeleb.github.io/clickmonkey/findings/V-02/)

Text or a control is cut off mid-glyph, not a clean ellipsis. Names and amounts become unreadable.

Table cells, colliding column headers, and a trailing icon sitting on the letters. Clean ellipsis is not this. Collapsed icon-rail labels (icon-only nav, `data-sidebar`, or a flush icon strip) are not this.

This id is **stable**. Reports link here so T/V/Q classes do not shuffle when a soak ranks differently.
