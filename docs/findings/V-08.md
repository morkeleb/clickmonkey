**Chapter:** visual  
**Rule:** `contrast`  
**Spec:** [Unreadable contrast (pixels)](https://morkeleb.github.io/clickmonkey/findings/V-08/)

AXE color-contrast is the ratio check (Deque). This id is a pixel-only miss that check did not fire on.
