# V-04 — Covered hit target

**Chapter:** visual  
**Rule:** `zIndex`  
**Spec:** [Covered hit target](https://morkeleb.github.io/clickmonkey/findings/V-04/)

A control is covered so it cannot be read or used. The click hits whatever is on top.

elementFromPoint at the control center is something else. Sticky nav and an open dialog covering the page behind it are expected.

This id is **stable**. Reports link here so T/V/Q classes do not shuffle when a soak ranks differently.
