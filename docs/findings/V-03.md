# V-03 — Overlap

**Chapter:** visual  
**Rule:** `overlap`  
**Spec:** [Overlap](https://morkeleb.github.io/clickmonkey/findings/V-03/)

Two things occupy the same pixels. Users mis-click or cannot read a label.

Two actable controls sharing a box. Parent/child and an open menu covering the page are not this.

This id is **stable**. Reports link here so T/V/Q classes do not shuffle when a soak ranks differently.
