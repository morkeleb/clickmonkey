# T-11 — Drifted locator

**Chapter:** testability  
**Rule:** `driftId`  
**Spec:** [Drifted locator](https://morkeleb.github.io/clickmonkey/findings/T-11/)

The control is still there but its name or locator moved. Old tapes and specs click the wrong widget or none.

Inspect marked the widget as drifted. Not this: zero matches (T-10); two widgets share one locator (T-12).

This id is **stable**. Reports link here so T/V/Q classes (and A-2.1.1) do not shuffle when a soak ranks differently.
