# Q-05 — Long tab title

**Chapter:** quality  
**Rule:** `document-title-long`  
**Spec:** [Long tab title](https://morkeleb.github.io/clickmonkey/findings/Q-05/)

The title is longer than ~60 characters and will truncate in search results and tabs.

Keep the unique part first so a truncated tab still names the page. Not this: a missing title (WCAG 2.4.2); a leftover Create Next App / Vite string (Q-04).

This id is **stable**. Reports link here so T/V/Q classes do not shuffle when a soak ranks differently.
