# WCAG 2.5.8 Target size

**Chapter:** accessibility · WCAG 2.5.8 AA  
**Rule:** `targetSize`  
**WCAG:** [WCAG 2.5.8 Target size](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html) — official.

The control is smaller than 24×24 CSS pixels and too close to another target, so taps miss or hit the neighbor. Isolated tiny icons with a 24px-clear circle still pass; inline text links are not this.

This handle is only “we found `targetSize`.” The requirement is the W3C page, not this catalog.
