# T-08 — Occluded widget

**Chapter:** testability  
**Rule:** `occludedWidget`  
**Spec:** [Occluded widget](https://morkeleb.github.io/clickmonkey/findings/T-08/)

A control is covered by another layer. Sighted users may still guess; the walker and keyboard users cannot activate it.

Sticky chrome, leftover overlays, and stacked dialogs hide the click target. Open menus covering the page behind them are expected.

This id is **stable**. Reports link here so T/V/Q classes (and A-2.1.1) do not shuffle when a soak ranks differently.
