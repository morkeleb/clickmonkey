# Q-15 — Console warning

**Chapter:** quality  
**Rule:** `console.warning`  
**Spec:** [Console warning](https://morkeleb.github.io/clickmonkey/findings/Q-15/)

The runtime logged a warning. Most are library noise; read the message before treating it as a product bug.

A warning is not a crash. Not this: console.error (Q-14); uncaught JavaScript (Q-16).

This id is **stable**. Reports link here so T/V/Q classes do not shuffle when a soak ranks differently.
