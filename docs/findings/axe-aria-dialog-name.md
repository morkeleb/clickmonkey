# AXE aria-dialog-name

**Chapter:** accessibility · WCAG 4.1.2 A  
**Rule:** `aria-dialog-name`  
**axe:** [AXE aria-dialog-name](https://dequeuniversity.com/rules/axe/4.13/aria-dialog-name) — official.

The dialog has no accessible name. Screen readers say “dialog” with no title, and inspect cannot tell two modals apart.

This handle is only “we found `aria-dialog-name`.” The requirement is the Deque page, not this catalog.
