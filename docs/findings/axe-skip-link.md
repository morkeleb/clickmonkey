# AXE skip-link

**Chapter:** accessibility · WCAG 2.4.1 A  
**Rule:** `skip-link`  
**axe:** [AXE skip-link](https://dequeuniversity.com/rules/axe/4.13/skip-link) — official.

The skip link does not point at a focusable target. Keyboard users cannot jump past chrome.
