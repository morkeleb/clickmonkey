# Q-17 — Not found

**Chapter:** quality  
**Rule:** `notFound`  
**Spec:** [Not found](https://morkeleb.github.io/clickmonkey/findings/Q-17/)

A link, hop, or redirect led to a missing page, including a soft SPA 404. Users hit a dead end.

HTTP 404 and an in-app 404 page (the document can still return 200) are this class. The rest of that path is dropped from the map. Not this: a generic HTTP 4xx/5xx that is not 404 (Q-18).

This id is **stable**. Reports link here so T/V/Q classes do not shuffle when a soak ranks differently.
