# T-05 — Unnamed control

**Chapter:** testability  
**Rule:** `unnamedControl`  
**Spec:** [Unnamed control](https://morkeleb.github.io/clickmonkey/findings/T-05/)

The control has no name. People using a keyboard or a reader skip it; the walker cannot click it on purpose.

Buttons and links need discernible text or an aria-label. Icon-only without a name is this class.

This id is **stable**. Reports link here so T/V/Q classes (and A-2.1.1) do not shuffle when a soak ranks differently.
