# T-07 — No main landmark

**Chapter:** testability  
**Rule:** `noMain`  
**Spec:** [No main landmark](https://morkeleb.github.io/clickmonkey/findings/T-07/)

There is no main landmark. Skip-to-content and the walker’s “this is the page” heuristic fall back to chrome.

One <main> or role=main per page. Multiple mains are a quality/html-validate finding instead.

This id is **stable**. Reports link here so T/V/Q classes do not shuffle when a soak ranks differently.
