# Q-07 — Same tab title on every record

**Chapter:** quality  
**Rule:** `document-title-instance`  
**Spec:** [Same tab title on every record](https://morkeleb.github.io/clickmonkey/findings/Q-07/)

Different records share one tab title, so two customer tabs can both say Customer.

Put the record name in the title. Not this: every route in the app sharing one title (Q-06); a missing title (WCAG 2.4.2).

This id is **stable**. Reports link here so T/V/Q classes do not shuffle when a soak ranks differently.
