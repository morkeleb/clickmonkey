# AXE label-title-only

**Chapter:** accessibility  
**Rule:** `label-title-only`  
**axe:** [AXE label-title-only](https://dequeuniversity.com/rules/axe/4.13/label-title-only) — official.

The field’s only name is title or a hidden label. Sighted users see a blank control; the accessible name is easy to miss.

This handle is only “we found `label-title-only`.” The requirement is the Deque page, not this catalog.
