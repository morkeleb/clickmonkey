# AXE aria-hidden-focus

**Chapter:** accessibility · WCAG 4.1.2 A  
**Rule:** `aria-hidden-focus`  
**axe:** [AXE aria-hidden-focus](https://dequeuniversity.com/rules/axe/4.13/aria-hidden-focus) — official.

An aria-hidden node is still focusable. Keyboard users land in a black hole (leftover overlay or SVG tabindex).

This handle is only “we found `aria-hidden-focus`.” The requirement is the Deque page, not this catalog.
