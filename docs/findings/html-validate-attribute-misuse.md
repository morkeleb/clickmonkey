# html-validate attribute-misuse

**Chapter:** quality  
**Rule:** `attribute-misuse`  
**html-validate:** [html-validate attribute-misuse](https://html-validate.org/rules/attribute-misuse.html) — official.

An attribute is on the wrong element. Assistive tech and validators ignore or misread it, so the intended name or state never arrives.

This handle is only “we found `attribute-misuse`.” The requirement is the html-validate page, not this catalog.
