# T-03 — Opaque control

**Chapter:** testability  
**Rule:** `opaqueControl`  
**Spec:** [Opaque control](https://morkeleb.github.io/clickmonkey/findings/T-03/)

The control has no accessible name. Assistive tech announces a blank widget, and the map cannot give it a stable id.

Icon-only chrome without aria-label or a visible label cannot be mapped or activated on purpose.

This id is **stable**. Reports link here so T/V/Q classes do not shuffle when a soak ranks differently.
