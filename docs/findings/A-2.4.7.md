# WCAG 2.4.7 Focus visible

**Chapter:** accessibility · WCAG 2.4.7 AA  
**Rule:** `focusVisible`  
**WCAG:** [WCAG 2.4.7 Focus visible](https://www.w3.org/WAI/WCAG22/Understanding/focus-visible.html) — official.

The control takes keyboard focus but shows no ring, glow, or border change (WCAG 2.4.7). Keyboard users cannot tell which control is active.

This handle is only “we found `focusVisible`.” The requirement is the W3C page, not this catalog.
