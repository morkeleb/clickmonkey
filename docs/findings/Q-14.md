# Q-14 — Console error

**Chapter:** quality  
**Rule:** `console.error`  
**Spec:** [Console error](https://morkeleb.github.io/clickmonkey/findings/Q-14/)

JavaScript or a network call failed on this page. The UI may look fine while a save, load, or widget is already broken.

Read the console.error text. Not this: an uncaught script crash (Q-16); a console warning (Q-15).

This id is **stable**. Reports link here so T/V/Q classes (and A-2.1.1) do not shuffle when a soak ranks differently.
