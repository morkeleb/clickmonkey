# T-06 — Unnamed dialog

**Chapter:** testability  
**Rule:** `unnamedDialog`  
**Spec:** [Unnamed dialog](https://morkeleb.github.io/clickmonkey/findings/T-06/)

The dialog has no accessible name. Screen readers say “dialog” with no title, and inspect cannot tell two modals apart.

aria-label, aria-labelledby pointing at the title, or a data-testid on the dialog host is enough.

This id is **stable**. Reports link here so T/V/Q classes (and A-2.1.1) do not shuffle when a soak ranks differently.
